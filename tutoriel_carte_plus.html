De la carte du module 3 à une carte d'analyse complète

Tutoriel pas à pas : 11 étapes pour construire, avec Leaflet seul, une carte de la défavorisation avec panneau d'analyse, filtres, matrice croisée, analyse de proximité et exports.
Santé Québec Laurentides · Direction de santé publique · Mise à jour : 2026-11-04

Avant de commencer

  • Votre carte du module 3 fonctionne, et le fichier laurentides_defavorisation.js est dans votre dossier de travail (ou celui du dossier secours/).
  • Un éditeur de texte : VS Code ou le Bloc-notes (dans ce cas, enregistrez avec Type : Tous les fichiers et Encodage : UTF-8).
  • Un navigateur, avec la console ouverte pendant les tests : F12 > Console.
  • Durée totale : environ 3 heures. Vous pouvez vous arrêter après n'importe quelle étape : la carte fonctionne toujours.

Comment se déroule le tutoriel

À l'étape 1, vous copiez un fichier complet, carte_analyse.html. Ensuite, chaque étape ajoute une capacité en collant de 1 à 4 blocs de code au-dessus d'un repère déjà présent dans le fichier. Vous n'avez jamais à modifier ni à supprimer le code existant.

Les messages de la console

  • « … is not defined » : une étape précédente manque, ou un bloc a été collé sous la ligne demarrer();.
  • « Identifier '…' has already been declared » : un bloc a été collé deux fois.
  • « Cannot set properties of null » ou « Cannot read properties of null » : le bloc HTML (repère B ou C) de l'étape n'a pas été collé.
  • « Unexpected token » : un bloc incomplet (une accolade ou une parenthèse manque). Recopiez le bloc entier avec le bouton Copier.
  • Messages jaunes « Tracking Prevention blocked access to storage » dans Edge : simples avertissements, sans effet sur la carte.

Comprendre le code

  • Les quatre repères. Le fichier contient quatre lignes qui commencent par ▲ REPÈRE. À chaque étape, vous collerez les nouveaux blocs au-dessus du repère indiqué. Vous n'aurez jamais à modifier le code déjà en place.
  • Les « rendez-vous ». Le cœur du code prépare des listes vides : quandPret (lancées une fois, quand la couche existe), quandRafraichir (après chaque changement), quandSelection (au clic sur une municipalité) et filtres (pour estomper). Chaque étape y inscrit ses propres fonctions avec .push().
  • Une fiche par municipalité. La fonction preparer() lit les propriétés du GeoJSON et crée une fiche m : nom, code, MRC (déduite des deux premiers chiffres du code), quintiles matériel (m.qm) et social (m.qs), centre géométrique (m.centre).
  • demarrer() reste toujours la dernière ligne. Elle crée la couche, puis lance les rendez-vous. C'est pour cela qu'on colle tout le code des étapes suivantes au-dessus du repère D.

Comprendre le code

  • invalidateSize() demande à Leaflet de recalculer la taille de la carte. Sans lui, après avoir replié le panneau, une bande grise resterait à gauche.
  • La méthodologie utilise la balise HTML <details>, qui se déplie toute seule au clic, placée dans un contrôle Leaflet en bas à droite.
  • Créer des éléments en JavaScript. Le bouton du panneau et le troisième onglet sont créés avec document.createElement() : pas besoin de modifier le HTML de l'étape 1.
